RepEAT – Food Rescue App

**Good Food, Great Price, Zero Waste.**

RepEAT is an Android application prototype that connects consumers with local merchants to purchase unsold food at discounted prices.

The app aims to reduce food waste while helping consumers save money and merchants generate additional revenue from surplus food.

## Features

- **Consumer:** Browse food listings, purchase Surprise Bags or selected items, and receive a pickup code.
- **Merchant:** Manage food listings, track orders, and verify customer pickups.
- **Driver:** Manage delivery orders and track delivery status.
- **Food Rescue:** Help reduce food waste through surplus food purchases.

## How to Download

1. Open the RepEAT GitHub repository.
2. Find the file **`RepEAT-APK.zip`**.
3. Click the file and select **Download raw**.
4. Extract the downloaded ZIP file.
5. Locate the `.apk` file inside.
6. Open the APK on your Android phone and install it.
7. If prompted, allow installation from unknown sources.

## Notes

RepEAT is currently a prototype for demonstration purposes. The application uses demo data and local device storage. Real payments, online accounts, and synchronization between multiple devices are not yet implemented.
